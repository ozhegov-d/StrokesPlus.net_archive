URL Extraction Logic:   
Browser Window: Extracts the URL directly from the address bar (uses Alt+D to select).  
Selected Text: Extracts the URL from the clipboard (copies the highlighted text).  
Fallback (No browser & no selection): Opens the "From file" menu for batch processing.  

> To use cookies, the easiest approach is to log in via a browser and set var browserForCookies = "firefox";
